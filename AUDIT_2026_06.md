## Fixed in this round (committed to `richard-images-2026-06`)

### Critical

**C1 — No visible keyboard focus indicators**
Was: `outline-style: none` globally with no replacement. Keyboard users could not see where they were on the page.
Fix: Added `:focus-visible` rule in `globals.css` with 2px solid amber outline + 2px offset. Plus a proper skip-to-main-content link visible only on keyboard focus.
*File: `src/app/globals.css`*

**C2 — Heading hierarchy skipped from H1 to H3 on service detail pages**
Was: "Transparent pricing in writing." rendered as an `<h3>` directly under the page H1 with no H2 in between. Screen readers report this as a broken hierarchy.
Fix: Promoted the pricing card heading from `h3` to `h2`. Affects all 18 service detail pages.
*File: `src/app/services/[slug]/page.tsx`*

**C3 — No skip-to-main-content link**
Was: Keyboard users had to tab through the entire 24/7 emergency strip + header nav (10+ tabs) before reaching page content.
Fix: Added `<a href="#main" class="skip-link">Skip to main content</a>` as the first focusable element in `<body>`. Added `id="main"` to the `<main>` element. The link is visually hidden until keyboard-focused.
*File: `src/app/layout.tsx`*

### High

**H1 — Dead `ServiceCard` import in services index**
Was: `src/app/services/page.tsx` imported `ServiceCard` but never rendered it (the page uses inline `<Link>` cards instead). Unused import increases bundle size and creates confusion for future devs.
Fix: Removed the import.
*File: `src/app/services/page.tsx`*

**H2 — Hardcoded phone number in CostEstimator**
Was: The "Call Now" link in the CostEstimator had `href="tel:(416) 805-6676"` literal string. Every other phone link sitewide reads from `client.phone`. If the number ever changes, this one would silently miss the update.
Fix: Added `import { client } from '@/data/client'` and replaced with `href={`tel:${client.phone}`}`.
*File: `src/components/CostEstimator.tsx`*

These were flagged by the auditors but are aesthetic polish or require asset work outside this PR's scope. None block sign-off.

| ID | Finding | Severity | Why parked |

| P6 | Touch targets <44px on some pill chips and footer links at desktop | Low | The 44px min-height rule already applies on mobile (`@media (max-width: 767px)` in globals.css). Desktop is mouse-driven. |
